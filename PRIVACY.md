# 隐私政策 / Privacy Policy

本插件只包含写作指令与一个把 `SKILL.md` 注册到 DeepSeek Harness 技能目录的本地插件模块。

- 不包含 MCP 服务器、后台服务、账号系统、分析或追踪。
- 插件本身不发起网络请求，不向任何外部服务发送你的论文、提示词、文件或个人信息。
- 你的文本由 DeepSeek Harness 宿主按其隐私政策与账号设置处理，本插件不改变宿主的数据处理与保留方式。
- 你可以随时通过宿主卸载插件，或删除复制到技能目录中的技能文件夹。

## English

This plugin contains writing instructions only, plus a local module that registers
its `SKILL.md` files with the DeepSeek Harness skill registry.

- No MCP server, hosted backend, account system, analytics, or tracking.
- The plugin makes no network calls and sends no manuscript text, prompts, files,
  or personal data to any external service.
- Your text is processed by the DeepSeek Harness host under its privacy policy and
  your account settings. This plugin does not change the host's data processing
  or retention.
- You can uninstall the plugin through the host, or remove the copied skill
  folders from your skills directory at any time.
